## 2. Which Briefing Structures Produced the Best Results

Comparing the 9 prompt documents (`01`, `05`, `10`, `14`, `32`, `33`, `34`) against their outcomes reveals a clear structural law:

1. **Best-Performing Briefing Pattern — The "Contract + Vertical Slice + Explicit Invariants" Prompt (`10_SESSION3_REVIEW_PROMPT.md`, `14_SESSION5_MAPS_PROMPT.md`, and Phase 1 `P1.1`/`P1.2` Task Contracts):**
   - **Single Responsibility:** Separates **Architecture/Plan**, **Adversarial Review**, **Code Implementation**, and **Creative Data Authoring** into distinct turns.
   - **Explicit Forbidden Actions ("Do NOT..."):** Explicitly states *"Do NOT weaken any `.schema.json` file"*, *"Do NOT reformat untouched JSON lines"*, *"Do NOT mutate `sys.modules` without `monkeypatch.setitem`"*, and *"Do NOT add fallback branches for test stubs"*.
   - **Vertical Slice First (`3 shots`, not `84 shots`):** Requires proving visual/audio quality on a 3-shot vertical slice (`S01_SH001`, `S01_SH002`, `S03_SH002`) with real rendered frame contact sheets (`frame 0`, `25%`, `50%`, `75%`, `last`) before touching full-episode data.
   - **Mandatory Subprocess Proof:** Requires pasting the actual exit code and summary line of both the targeted test file **and** the full regression suite + `docs_lint`.
2. **Worst-Performing Briefing Pattern — The "Mega-Prompt Bundling Code + Schema + 84 Creative Briefs + Render" (`05_SESSION2_PROMPT.md`, `32_REBUILD_V2_TASK1_PROMPT.md`, `33_TASK2_SCENE_BUILDING_PROMPT.md`):**
   - Bundling 4–6 subsystems plus 84 creative JSON objects into a single turn exhausts output attention, causing the model to template-loop creative fields, loosen schemas to bypass validation errors, and skip full-suite regression checks.
