## Must fix

**R1. S06_SH008: `drop_word_artifacts` drops a real line** (`videolane/ingest.py`, #202).
The "duplicate opening word" rule drops the first "Maybe." when a second "Maybe." follows more than 0.8 s later. It was written as a
"false start" rule for S06_SH008, but Gemini's G1 and ვანო's listen (16:11) show the clip holds two real "Maybe." lines by two soldiers
(voiced 0.19–0.63 and 1.63–2.11). In `whisper_edit_points` the in-point then moves to ≈1.6 s and cuts away the first line.
Fix: run the voicing check first and drop a duplicate only when it is not voiced. Whether S06_SH008 keeps all three lines or only the
script's "Maybe. But not today." is a creative cut for ვანო: record it as a REVIEW item. The unit test that asserts the drop
(`test_trim_rule.py` L116-117) encodes the old premise; replace it with a voiced/unvoiced pair (no weakening).

**R2. quality.yml guard can be bypassed by editing a step's command** (`governance/records.quality_yml_problems`, #205).
It only counts `- name:` and `run:` lines and some skip markers. A plan-thread record could turn `run: python -m pytest -q` into
`run: echo ok` with the same counts and pass. Fix: compare the set of `run:` command texts (every old command must still be present
verbatim), or refuse any change to an existing step under a plan-thread record and allow only added steps.

**R3. `route_proposals.json` is overwritten per scene** (`videolane/ingest.py` `ingest_scene` → `route_proposals`, #203).
Each scene's ingest re-evaluates the script with only that scene's first-frame comparisons and rewrites the file, so the last scene
wins and earlier scenes' comparison-based proposals are lost. Fix: merge into the file by shot id (or key it by scene), with a test of
two scenes in sequence.

## Should fix (small)

- **S1. Continuation shots inflate `unresolved_reviews`** (#203): `start_frame_check` gives every continuation NEEDS_EVIDENCE, so
  each one is counted as an open REVIEW. A continuation has no start picture by design. Give it its own state (e.g. `CONTINUATION`,
  not counted) and keep NEEDS_EVIDENCE for a genuinely missing picture.
- **S2. Older scene files skip the MA-05 re-hash** (`scene_run.job_spec`, #200): the "picture changed after its check" refusal runs
  only for `ltx_scene_test/3`. A paid job from a /2 scene file has no picture_check at all. Refuse a paid job from a scene
  without `picture_check` (write the scene again), with a test.
- **S3. Narrated clips' hallucinated tails are not muted** (#204): G8 applies `mute_tail_from_s` only to dialogue inserts. Ingest sets it only
  for spoken shots, but `whisper_edit_points` documents it for silent/narrated clips too. Either apply it to `narrated_clips` in
  `stage_sound` as well, or state in the record that narrated clips are out of scope. Today the two places disagree.
- **S4. Energy spans of spoken shots are still trusted** (#202): `trim_decision` keeps `R.speech_spans` (band energy) unfiltered as
  the base, so a gunshot inside a spoken clip still counts as a "speech" span for the edit points. Probably harmless (it keeps a
  sound), but say so in the docstring, or tag base spans that no voice supports.
