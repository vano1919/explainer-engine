**Date Accessed & Verified:** 2026-11-06 / 2026-11-07
**Scope:** Broad market evaluation of **18 GPU compute providers** (RunPod baseline + 17 alternatives) for the **Explainer Engine / Ink Chronicle** workload (`Qwen/Qwen-Image-2.1` + `xworld_v2` LoRA, `Lightricks/LTX-2.5` 22B video generation, `BiRefNet` cutouts, and `Blender 5.2.3` 2.5D/3D passes).

## 1. Epistemic Labeling Legend

Every claim in this document and across `docs/providers/` carries an explicit epistemic label:
- **`[VERIFIED FACT]`**: Directly confirmed in repository source code, official provider API documentation, or official pricing/status pages (with URL and access date).
- **`[MARKETING CLAIM]`**: Provider-advertised capability or SLA not independently verified on our workload.
- **`[OBSERVED RESULT]`**: Measured in historical project runs recorded in `docs/PROGRESS.md`, `MATERIAL.md`, or `LTX_HELPERS.md`.
- **`[ESTIMATE]`**: Arithmetic projection from measured/verified inputs using stated formulas.
- **`[ASSUMPTION]`**: Explicit modeling parameter used to compare providers on an equal footing.
- **`[RECOMMENDATION]`**: Engineering or operational proposal requiring creator (`OR-22`/`OR-23`) and/or Opus (`OR-24`) approval.
- **`[UNKNOWN / LIVE TEST REQUIRED]`**: Fact that cannot be settled from public documentation or offline code inspection.

## 3. Classification of All 18 Evaluated Providers (`[VERIFIED FACT]`)

Do not compare unlike service models as drop-in equivalents:
1. **Specialized Self-Serve GPU VM / Container Clouds (Direct RunPod Competitors):**
   - **RunPod (Current Baseline):** Container pods (`SECURE` and `COMMUNITY` clouds) + Serverless endpoints ([RunPod Docs](https://docs.runpod.io/)).
   - **Hyperstack (NexGen Cloud):** Full KVM Linux GPU Virtual Machines (`CANADA-1`, `NORWAY-1`, `US-1`) with included CPU/RAM/local NVMe + separate AI Studio (token/patch API) + Dedicated Inference ([Hyperstack Docs](https://docs.hyperstack.cloud/docs/api-reference/introduction/)).
   - **Lambda Cloud:** On-demand Linux GPU VMs and 1-Click Clusters ([Lambda Cloud Status](https://status.lambda.ai/), [Lambda Docs](https://hermes-agent.nousresearch.com/docs/user-guide/skills/optional/mlops/mlops-lambda-labs)).
   - **Nebius AI Cloud:** Per-second Linux GPU VMs (`1x` and `8x` presets) and Managed Kubernetes / Soperator in EU and US ([Nebius Pricing](https://nebius.com/prices), [Nebius Docs](https://docs.nebius.com/compute/resources/pricing)).
   - **Vultr Cloud GPU:** Global KVM GPU VMs (fractional and full cards) + Bare Metal across 32 regions ([ComputePrices Vultr](https://computeprices.com/providers/vultr), [Vultr API](https://bestusavps.com/best-for/machine-learning/)).
   - **Genesis Cloud:** European green-energy Linux GPU VMs ([Genesis Cloud Developers](https://developers.genesiscloud.com/compute-api/instance-types), [Genesis Cloud Pricing](https://computecomparison.com/provider/genesis-cloud)).
   - **Crusoe Cloud:** Clean-energy GPU VMs and clusters ([ComputePrices Crusoe](https://computeprices.com/providers/crusoe)).
   - **Paperspace (by DigitalOcean) / DigitalOcean GPU Droplets:** Subscription-gated GPU VMs/Notebooks (Paperspace) and self-serve GPU Droplets ([DigitalOcean GPU Droplets](https://www.digitalocean.com/products/gpu-droplets), [Paperspace Pricing](https://www.spheron.network/blog/paperspace-pricing-2026/)).
2. **Serverless Python GPU Execution Platforms:**
   - **Modal:** Python-native serverless GPU Functions and Sandboxes with per-second billing, scale-to-zero, and distributed Volumes ([Modal Pricing](https://modal.com/pricing), [Modal GPU Guide](https://modal.com/docs/guide/gpu)).
3. **Peer-to-Peer / Host-Set GPU Marketplaces:**
   - **Vast.ai:** Container marketplace over independent datacenter and consumer hosts with granular offer search ([Vast.ai Search Offers API](https://docs.vast.ai/api-reference/search/search-offers)).
   - **TensorDock (acquired by Voltage Park, March 2025):** KVM VM marketplace of independent hosts ([TensorDock](https://tensordock.com/), [RunPod Lambda Alternatives](https://www.runpod.io/articles/alternatives/lambda-labs)).
   - **CUDO Compute:** Aggregated data-center marketplace with REST API and CLI ([CUDO vs Salad](https://computeprices.com/compare/cudo-compute-vs-salad)).
   - **SaladCloud:** Distributed consumer/gaming PC container grid (`Salad Container Engine`) + Dedicated tier ([SaladCloud](https://salad.com/), [ComputePrices Salad](https://computeprices.com/providers/salad)).
4. **Enterprise Cluster-Only / Contract-Gated Neoclouds:**
   - **CoreWeave:** Kubernetes-native (`CKS`) HGX cluster provider; on-demand H100/H200 sold only in **8-GPU node minimums** (`$49.24/hr` node = `$6.16/GPU-hr`) ([CoreWeave vs Nebius](https://www.spheron.network/blog/coreweave-vs-nebius-h100-and-h200-pricing-2026/)).
   - **Fluidstack:** Contracted bare-metal Slurm/Kubernetes clusters for AI labs; no self-serve single-GPU on-demand console ([Fluidstack](https://fluidstack.io/), [Fluidstack vs Runcrate](https://getdeploying.com/fluidstack-vs-runcrate)).
5. **Traditional Hyperscalers (Quota-Gated, High On-Demand Markup):**
   - **AWS EC2 (`P5`, `P4d`, `G6e`):** Full cloud ecosystem, `1.7x–2.7x` higher on-demand GPU prices (`p5.4xlarge` 1x H100 = `$6.88/hr`, Capacity Blocks `$5.19/hr`, `0.09/GB` egress) ([GoogieHost GPU Guide](https://googiehost.com/blog/best-cloud-gpu-rentals-ai-ml/), [WindowsForum 2026 Guide](https://windowsforum.com/news/cloud-gpu-pricing-guide-2026-compare-azure-aws-runpod-vast-ai-and-more.448998/)).
   - **Google Cloud Compute Engine (`A3`, `A2`, `G2`):** `a2-ultragpu-1g` (1x A100 80GB) = `$5.07/hr` (`$2.93/hr` Spot), `a3-highgpu-1g` (1x H100 80GB) = `$9.80/hr` ([GPULedger](https://gpuledger.dev/instances/), [WindowsForum 2026 Guide](https://windowsforum.com/news/cloud-gpu-pricing-guide-2026-compare-azure-aws-runpod-vast-ai-and-more.448998/)).
   - **Microsoft Azure (`ND H100 v5`, `NC A100 v4`):** `ND96isr H100 v5` sold as 8x H100 (`$88.49–$98.32/hr` node = `$11.06–$12.29/GPU-hr`) ([GPULedger](https://gpuledger.dev/instances/), [Uvik GPU Price Index](https://uvik.net/blog/gpu-price-index/)).
