## 3. Stock Monitoring & Selection Architecture (`explainer_engine/cloud/providers/`)

To integrate cleanly with `explainer_engine/cloud/runpod.py` (`pick_gpus`) and `explainer_engine/cloud/jobs.py` (`Job`), our provider-neutral capacity selector enforces:
1. **Zero-Cost Read-Only Polling with TTL Cache & Stale-Data Rejection:**
   - Inventory snapshots carry an explicit `fetched_at` Unix timestamp and `max_age_s` (default `120 s`).
   - If `now - fetched_at > max_age_s`, the snapshot is marked `stale = True` and **cannot** be used to authorize a launch decision (`StaleStockError`).
   - Polling is rate-limited (`min_poll_interval_s = 30.0`) and honors HTTP `429` `Retry-After` headers.
2. **Hard Workload Compatibility Gate Before Ranking (`can_run`):**
   - Rejects any GPU offer where `vram_gb < workload.min_vram_gb` (`80 GB` for `p12b`/`p14` combined Qwen+LTX, `48 GB` for isolated Qwen-Image, `24 GB` for BiRefNet/lightweight tasks).
   - Rejects any offer where `ephemeral_plus_root_disk_gb < workload.min_disk_gb` (`200 GB` for combined Qwen+LTX).
   - Rejects any offer where `cuda_version < workload.min_cuda` (`12.4` for smoke, `12.8` default).
3. **Total-Job Cost Ranking (Not Headline $/hr):**
   - Following the creator's 2026-10-24 rule in `runpod.py:317` (*"the cheapest JOB, not the cheapest hour"*), each candidate is scored by:

   - Enforces **RP-01** (`work_min >= 3 * setup_min`) and **RP-09** (`setup_share <= 0.40`).
   - Breaks ties by stock confidence (`HIGH > MEDIUM > LOW`, or verified data-center VM over unverified peer host) so a reliable data-center card (`Hyperstack A100-80G PCIe @ $1.35/hr` or `RunPod A100-80G @ $1.39/hr`) wins over an unverified marketplace host when estimated job cost is within margin.
