# Wave Next Architectural Decisions

1. **Preserve Episode-First Core (`episode/run.py`) — Zero Rewrite:** All new capabilities extend the existing deterministic runner, `SkillOrchestrator`, `approvals.py`, and `spend_ledger.py`.
2. **Unified Execution Gateway (`core/execution_gateway.py`):** Introduce a persistent JSON/SHA-256 state machine that tracks stage inputs/outputs, invalidates downstream stages when upstream artifacts change, enforces mandatory stage ordering, and prevents Claude Opus from marking any stage PASS without machine-verifiable artifact hashes.
3. **Strict Still vs Video Adapter Separation (`videolane/adapters.py`):** Split `StillUpscalerAdapter` (`realesrgan_x2`, `lanczos_cas`) from `VideoUpscalerAdapter` (`ltx_pixel_spatial_upscaler`, `seedvr2_4n1`, `ffmpeg_2k_lanczos`) and wrap LTX generation behind an interchangeable `LTXGenerationAdapter` governed by `approvals.py` and `spend_ledger.py`.
4. **Resolve Map Raster Typography (`maps/draw.py`):** Replace hardcoded `Inter.ttf` with `Liberation Serif` (approved map typography across `1917_film.json` and `truce_cold.json`), falling back cleanly only when Liberation Serif is absent on a host.
5. **Connect Visual Bridges to HyperFrames (`overlay/bridge_compiler.py`):** Compile validated `docudrama_structure.py` visual bridges directly into `overlay_spec/2` JSON + deterministic FFmpeg overlay render.
6. **Post-Assembly Visual-Aware Sound Spotting (`audio/post_assembly_spotting.py`):** Add a SHA-256-pinned post-assembly spotting workflow that invalidates automatically if the assembled video changes, enforces library-first SFX + approved ElevenLabs fallback, and supports measured A/B comparison of 30ms anti-pop cut fades.
7. **Calibrated Cross-Scene Identity Lock (`qa/identity_lock.py`):** Use commercial-safe YuNet+SFace (MIT/Apache-2.0) with confidence-aware `REVIEW` verdicts (never arbitrary `FAIL` on back-facing, occluded, or distant faces).
8. **Deterministic Claude Opus Governance (`governance/hooks.py` + `CLAUDE_OPUS_PRODUCTION_HANDOFF.md`):** Extend existing Claude Code hooks to validate gateway state and prevent direct bypasses; document exact operational handoff for Claude Opus.
