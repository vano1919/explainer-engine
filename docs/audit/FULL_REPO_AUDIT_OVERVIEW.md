## 1. Executive Summary & 7-Goal Gap Rollup

### The 7 Target Goals Audited Against
1. **G1 (90% Automated Separation of Creative vs. Deterministic Authority):** Clean boundary between creative authoring and deterministic Python execution/gating, single authoritative stage graph.
2. **G2 ($0.00 Default Spend & Unforgeable Remote HMAC/Registry Security):** Zero default spend, unforgeable owner approvals (non-writable by agent, single-use replay-protected, HMAC-signed for remote workers), single transactional spend ledger.
3. **G3 (Constrained Claude Code Control Plane):** Fail-closed hooks, `permissions.deny`, full hook lifecycle coverage, robust cross-platform shell & tool parsing.
4. **G4 (Visual Pipeline):** Coherent active stack (`map_action`, `still_25d`, `video`/Modal LTX-2.5, Blender grey-box previs), unified camera vocabulary, flexible story-driven visual mix (no hardcoded 10/30/60 quota).
5. **G5 (Audio & Post-Assembly Spotting):** Word-synced timing, free-library-first sound plan, mandatory post-assembly visual spotting wired into the stage graph.
6. **G6 (Multi-Layer QA & Identity Lock):** Real 3-layer QA, accurate character identity lock (never substituting shot 0 blindly), intact schema/contract enforcement.
7. **G7 (Cross-Platform Windows/Linux Parity & Zero Doc Drift):** POSIX/Windows path, locking, shell, and CI parity; zero contradiction between code, configs, `.claude/agents/`, `.agents/skills/`, and `README.md`.
